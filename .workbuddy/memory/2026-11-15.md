## 新增「专项练习」板块（App v1.4）

- 需求：`二、专项练习（做·练）` 里的题目没进题库，要收进来；并且 App 页面上把「专项练习」和「套卷模考」分开。
- 数据链路：`_build/drill_extract.py`（191 个源文件 → `raw_drill/*.txt`）→ `_build/drill_parse.py`
  （→ `_build/drill_bank.json`）→ `_build/build_html.py`（注入 `<script id="drill">`）→ `npm run sync`。
- 结果：**102 个专项题库 / 12166 题**（有答案 10779、解析 5880、无答案自测 1387），8 个分类：
  公基分模块 30 / 基础强化 23 / 预测押题 3 / 行测分模块 25 / 必做100题 4 / 常识分类 5 / EPI 6 / 行测押题 4。
- `.doc` 坑：99 个 .doc 里 24 个（法理学题库、438道、数字推理725、行测专项题库等）LibreOffice Kit 报
  `invalid or truncated compound-file header`，改用本机 Word COM 转 docx：`_build/drill_doc2docx.ps1`
  （需 danger-full-access；`powershell -File` 读 UTF-8 无 BOM 会报语法错，要用 `pwsh -File`）。
- 解析坑：二、专项练习格式比套卷杂得多，做了两套切题器取优（标准 parse.py 逻辑 + 宽松切题器），并补了：
  `试题N：`/`【第N题】`/`【例N】`题号、`A，`/`A:`/粘连中文的选项、`（C）`/`（答案：A）`/`故选C`/纯字母行答案、
  `[答案]`方括号、答案版文件按标题配对。踩过的雷：
  - 只按「选项块前最近题号」定位会把长材料里的数字当题号 → 题干被截断；
  - 改成「期望下一题号」后，分段重新编号的题库会大量漏题，反而更糟 → 最终回退成原方案，靠两套取优兜底。
- App 改动（template.html）：
  - 顶部三页签 `📝 套卷模考 / 🧩 专项练习 / 📖 阅读学习`；`curBank` 记录当前板块，首页/分类页/返回都按板块走；
  - 专项题库复用套卷的做题逻辑，但 `goChooseMode` 隐藏模考面板、`startPaper` 强制 practice；
  - `LETTERS` 扩到 A-E（有 5 选项题库）；`.seg` 加 `min-width:0/overflow:hidden`，否则三页签会把 390px 宽度撑破；
  - `test_app.js` 增加专项板块 8 项断言，并修掉旧的「必须有答案」断言（na 题不该算非法）。
- 验证：`node _build/test_app.js` **150/150**；无头 Chrome（iframe 锁 390px 宽）截图看过
  专项首页/分类页/选择页/做题页/套卷首页/阅读首页，均无横向溢出。
- 交付：`延长石油套卷模考.html` 11.69 MB、`延长石油刷题-v1.4-专项练习.apk` 298 MB（versionCode 5）。
- 已知取舍：排除「计算机基础知识专题」（答案与题序错位）；少量长材料题库个别题干会并进下一题选项，
  答案仍按原卷序号映射，可在 App 里用 AI 解析兜底。
